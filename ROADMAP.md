# Learning Roadmap

Roadmapa jest kierunkowa. Przejście dalej zależy od dowodów kompetencji, nie od samego upływu czasu.

## Etap 0 — Audyt praktyczny

- Zweryfikować środowisko Python i terminal.
- Sprawdzić samodzielność w podstawowych zadaniach.
- Zidentyfikować luki w podstawach.

**Warunek wyjścia:** wiarygodny punkt startowy w `PROGRESS.md`.

## Etap 1 — Python Foundations

- Typy danych i zmienne.
- Operatory i wyrażenia.
- Instrukcje warunkowe i pętle.
- Kolekcje: `list`, `tuple`, `dict`, `set`.
- Funkcje, zakres zmiennych i argumenty.
- Praca z tekstem i plikami.
- Wyjątki.

**Warunek wyjścia:** samodzielne rozwiązanie zestawu zadań bez kopiowania gotowego kodu oraz umiejętność wyjaśnienia rozwiązania.

## Etap 2 — Intermediate Python

- Moduły i pakiety.
- OOP: klasy, obiekty, kompozycja.
- Dataclasses.
- Type hints.
- JSON, CSV, `pathlib`.
- Iteratory i generatory.
- Standard library.
- Zarządzanie zależnościami i `venv`.

**Warunek wyjścia:** mały, modularny program z czytelnym podziałem odpowiedzialności.

## Etap 3 — Software Engineering

- Struktura projektu.
- Separation of Concerns.
- Czytelność i refaktoryzacja.
- Obsługa błędów.
- Logging.
- Podstawy projektowania i dokumentowania kodu.

## Etap 4 — Testing & Debugging

- Testy jednostkowe.
- pytest.
- Fixtures i parametryzacja.
- Debugowanie tracebacków.
- Testy regresyjne.
- Podstawy mockowania, gdy pojawi się uzasadniona potrzeba.

## Etap 5 — Developer Workflow

- Git: status, diff, commit, branch, merge.
- GitHub: repozytoria, README, Issues i Pull Requests.
- Linux: pliki, uprawnienia, procesy, potoki i przekierowania.
- VS Code: debugger, terminal i praca z interpreterem.

## Etap 6 — Databases & APIs

- SQL i SQLite.
- CRUD i relacje.
- HTTP, JSON i REST.
- Klient API i obsługa błędów komunikacji.

## Etap 7 — Projects & Career

- Małe projekty.
- Symulacje zadań od klienta.
- Czytanie cudzego kodu.
- Code review.
- Portfolio i przygotowanie rekrutacyjne.

## Reguła zakresu

Nie uczymy wszystkich tematów równolegle. Mentor wybiera następny temat na podstawie zależności, luk i aktualnych dowodów.
