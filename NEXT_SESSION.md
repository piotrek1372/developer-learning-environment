# Next Session

## Cel główny

Przeprowadzić krótki audyt środowiska i praktyczny test poziomu Python.

## Kolejność

1. Sprawdzić wersję Pythona i dostępność `python`, `python3`, `git`.
2. Potwierdzić, że VS Code otwiera katalog projektu.
3. Wykonać krótkie zadanie diagnostyczne z Pythona.
4. Poprosić ucznia o wyjaśnienie rozwiązania.
5. Ocenić tylko te kompetencje, które mają bezpośrednie dowody.
6. Zaktualizować `PROGRESS.md` po akceptacji.

## Zasady

- Nie instalować pakietów, dopóki nie wiadomo, że są potrzebne.
- Nie zmieniać konfiguracji systemu.
- Nie podawać pełnego rozwiązania przed samodzielną próbą.
- Jedno zadanie diagnostyczne naraz.

## Zadanie do rozpoczęcia

Mentor powinien najpierw poprosić o wyniki poleceń:

```bash
python --version
python3 --version
git --version
```

Jeśli któreś polecenie nie działa, zanotować dokładny komunikat. Nie zakładać, że brak komendy oznacza brak instalacji — sprawdzić sytuację ostrożnie.
