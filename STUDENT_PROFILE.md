# Student Profile

## Cel

Przygotowanie do pracy jako Junior Python Developer.

## Aktualny priorytet

Python. Pozostałe technologie mają wspierać ten cel, a nie konkurować z nim o uwagę.

## Środowisko

- System: Arch Linux (informacja z dotychczasowego kontekstu; konfiguracja wymaga lokalnej weryfikacji).
- Edytor: Visual Studio Code.
- Dostęp do ChatGPT: przeglądarka Firefox.
- Model współpracy: ChatGPT + lokalne repozytorium + Git/GitHub.
- Synchronizacja: ręczna.

## Preferowany sposób nauki

- Krótka, konkretna teoria.
- Ćwiczenia praktyczne.
- Stopniowane wskazówki.
- Samodzielne próby przed otrzymaniem gotowego rozwiązania.
- Małe, ukończone projekty.
- Profesjonalny code review i uzasadnianie decyzji.

## Obszary do uwzględnienia

Dotychczas pojawiały się ćwiczenia z podstaw Pythona, funkcji, struktur danych, OOP, JSON, wyjątków, pytest i podstaw Git. To nie jest potwierdzenie poziomu biegłości — każdy obszar należy weryfikować praktycznie.

## Ryzyka organizacyjne

- Nadmierne komplikowanie zadań.
- Rozpraszanie uwagi i rozpoczynanie zbyt wielu wątków.
- Zbyt duże poleganie na AI podczas rozwiązywania problemów.

System powinien przeciwdziałać tym ryzykom przez ograniczanie zakresu, krótkie iteracje i wymaganie samodzielnych wyjaśnień.
