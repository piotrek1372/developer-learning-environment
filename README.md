# Developer Learning Environment (DLE)

Osobiste środowisko nauki i praktyki przygotowujące do pracy jako Junior Python Developer.

## Założenia

- Główny priorytet: Python.
- Język mentoringu: polski; nazewnictwo techniczne również po angielsku.
- Edytor: Visual Studio Code.
- System lokalny: Arch Linux.
- ChatGPT w przeglądarce Firefox; synchronizacja stanu odbywa się ręcznie.
- To repozytorium jest głównym źródłem prawdy o postępach.

## Rozpoczęcie pracy

1. Otwórz katalog repozytorium w VS Code.
2. Przeczytaj `SYSTEM.md`.
3. Uzupełnij lub skoryguj `STUDENT_PROFILE.md`.
4. Przed sesją udostępnij ChatGPT aktualne `PROGRESS.md` i `NEXT_SESSION.md`.
5. Po sesji zatwierdź proponowane aktualizacje plików.
6. Zapisuj zmiany w Git.

## Struktura MVP

- `SYSTEM.md` — reguły działania środowiska.
- `STUDENT_PROFILE.md` — profil i preferencje ucznia.
- `ROADMAP.md` — kolejność nauki.
- `PROGRESS.md` — kompetencje i dowody.
- `NEXT_SESSION.md` — następny konkretny krok.
- `DECISIONS.md` — istotne decyzje architektoniczne.
- `skills/learning-mentor/SKILL.md` — specyfikacja mentora.
- `workflows/daily-learning.md` — przebieg sesji.
- `knowledge/SOURCES.md` — podstawowe źródła wiedzy.

## Ważne

Ten pakiet jest przygotowanym starterem. Nie oznacza, że został już umieszczony na Twoim komputerze, podłączony do GitHub ani przetestowany w Twoim środowisku.
